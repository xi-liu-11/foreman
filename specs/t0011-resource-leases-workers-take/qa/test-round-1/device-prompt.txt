## Shared devices
This project's devices are shared with other Foreman workers: `android-emu`, `ios-sim`. Before you boot, build for, install on, or run flows against one of them, take its lease: `task lease android-emu --wait 540 --reason "<what for>"`, run with a Bash timeout of 600000 ms. Waiting is normal, not a failure: the command prints who holds the device and your place in the queue every 30 s. If it exits with code 3 you are still queued; run it again to keep your place. Keep running jest, tsc, lint and other device-free checks without a lease. Run `task release android-emu` as soon as the device phase is over (leases are also released when your step ends). If you need several devices, take them in alphabetical order. Never kill, shut down, erase or reinstall over another process's simulator, emulator, browser or Maestro run; if a device looks stuck, record it with `task note` and wait.
